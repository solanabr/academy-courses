Six pieces, one folder

What the installer adds to your project

1
House rules
Loads every session. Open the hub before Solana work, checked arithmetic, devnet first, close with Done / Warnings / Open.
CLAUDE.md
2
Skills
Markdown read before work. A hub maps one task to one file. Four packs installed, around forty more on demand.
.claude/skills/SKILL.md
3
15 agents
Specialist prompts with a name, a description and a model. Start on a description match or when you name one.
.claude/agents/
4
54 commands
Slash commands, each a markdown file. /doctor, /deploy, /quick-commit, /plan-feature, /firewall.
.claude/commands/
5
4 MCP servers
Helius for on-chain data, the Foundation's docs server, Context7 for library docs, context-mode for big outputs.
.mcp.json  + keys in .env
6
Firewall
Permission and sandbox rules from a tier, guard hooks, and the safe-ai-skill plugin. Default tier: Relaxed.
.claude/security.json  ·  .claude/hooks/
Only the house rules and the one-line descriptions load in every session. Everything else is read when a task calls for it. Counts as read on 2026-11-09, kit 2.4.0.
