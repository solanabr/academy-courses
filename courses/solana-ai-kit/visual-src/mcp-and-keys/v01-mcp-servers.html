The four MCP servers and where the one key goes

ServerWhat Claude uses it forNeeds a key?
HeliusOn-chain data: RPC, parsed transactions, token and NFT data, webhooks, priority fees.yes, HELIUS_API_KEY
solana-devThe Solana Foundation's docs server, remote over HTTP: docs, guides, API references.no
Context7Up-to-date library documentation lookup.no
context-modeKeeps large tool output out of the conversation. The one default with a code executor.no, Node 22.5+
Keys live in .env
Never in .mcp.json, which reads HELIUS_API_KEY from the environment so the config can be shared and the secret cannot.
/setup-mcp appends, never reads
One KEY=VALUE line at a time. bash .claude/bin/env-keys.sh prints each key as set or empty, never a value.
.env.schema has names only
A varlock schema, safe to commit and safe for Claude to read. varlock run --inject vars -- claude loads values from a secret manager instead.
