wire a rung into the supervisor

a standalone script, in three moves

1
register it in the manifest as an agent row
row = { "name": "face", "cmd": ["python", "watcher.py"], "chain": None, "key": None }
2
spawn it from the supervisor's start path, record the pid back
pid = subprocess.Popen(row["cmd"]).pid
manifest.set_pid(row["name"], pid)  # now reconciled on every resume
3
point it at the shared state/ dir, not its own private memory
env = { "STATE_DIR": "state/" }  # face paints from the shared cursor + manifest
A standalone script becomes a child the supervisor spawns, reconciles, and resurrects — same three moves for every rung.
