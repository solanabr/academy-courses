// yes → leave it running (do NOT double-spawn)
// no  → respawn, rewrite pid (recover the orphan)
a pid you don't reconcile is a liability
stale pid 40413 trusted blindly — OS recycled it → reads "still alive" → agent never respawned → orphaned funded key
kill 40413 → signals the wrong process → real agent survives, an innocent bystander dies
