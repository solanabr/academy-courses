the is_writable flag decides

read-sharing is free, write-sharing collides

shared write serialized

Alice → writes dex_pool
↓ Carol waits for the next batch ↓
Carol → writes dex_pool
writable sets intersect — runs single file

shared read parallel

Dave → reads dex_pool
Erin → reads dex_pool
is_writable = false on each — runs side by side
Sealevel intersects only the writable sets, never the full account lists. A shared account chokes only when someone writes it — the deciding field is the is_writable flag, not the address it points at.
