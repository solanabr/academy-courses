how find_program_address builds a keyless address

a bump search for an off-curve point

inputs
seeds [b"vault", owner_pubkey]
+ program_id
↓
decrement bump, hash, test the point
255
hash(seeds, 255, program_id) lands ON the curve
on curve = has a key — reject
254
hash(seeds, 254, program_id) lands ON the curve
on curve = has a key — reject
253
hash(seeds, 253, program_id) lands OFF the curve
off curve = no key — accept
↓
the vault PDA
a valid address with no private key behind it
canonical bump
= 253

The first (largest) bump that works. Store it once.

The program later "signs" by re-supplying [b"vault", owner_pubkey, 253] — no key required.
