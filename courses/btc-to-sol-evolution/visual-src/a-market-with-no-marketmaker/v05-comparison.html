one determinism rule, two opposite faces

the oracle problem is determinism's flip side

the rule underneath both
Every node must compute an identical result from identical inputs, or consensus breaks.

what it gives you module 0 — the hash

a hash is pure computation over its inputs, nothing external
every machine recomputes the same digest, forever
→ reproducibility you can trust

what it forbids this pool — a live price fetch

a live price fetch would read the outside world mid-execution
node A and node B call a second apart and get different numbers
→ they disagree on state — no consensus
