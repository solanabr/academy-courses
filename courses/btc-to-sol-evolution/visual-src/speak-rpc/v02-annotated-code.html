the json-rpc envelope, field by field

read the request, read both replies

request — what you send
{
  "jsonrpc": "1.0",  # protocol version
  "id": "demo", # echoed back
  "method": "getblockchaininfo",
  "params": []  # positional array
}
success response
{
  "result": { "chain":"regtest" … },
  "error": null,  # null means it worked
  "id": "demo"  # matches what you sent
}
error response
{
  "result": null,  # nothing to return
  "error": { "code": -8, … }, # node refused
  "id": "demo"
}
the thread every reply carries back the same "id" you sent — that is how you match a response to its request.
