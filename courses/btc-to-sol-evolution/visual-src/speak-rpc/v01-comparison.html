one call, three costumes

same request, different ceremony

bitcoin-cli

what it hides
port, cookie, the JSON envelope, the response unwrap
what you write
a method name
best for
humans at a terminal

curl

what it hides
nothing
what you write
the full envelope + auth, by hand
best for
seeing the raw wire, quick debugging

requests.post

what it hides
nothing you did not choose to hide
what you write
the envelope as a dict
best for
programs, bots, everything in this course
All three send the same JSON body to the same port and get back the same result — they differ only in how much ceremony is pre-filled.
