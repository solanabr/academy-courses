the day one line points at mainnet

devnet was a kindness. mainnet charges for the truth.

devnet / regtest — training wheels

moneyfree from a faucet, worthless
adversariesnone — nobody is trying
mistakesredeploy them away for free
a green test suite meansyour code runs

mainnet — the real thing

moneyreal, and the balance is someone's
adversariesstanding, and breaking you pays
mistakespermanent state, real loss
a green test suite meansyour code runs (not that it's safe)
A passing suite proves your code runs. On mainnet, the untested case is the one an adversary is paid to find.
