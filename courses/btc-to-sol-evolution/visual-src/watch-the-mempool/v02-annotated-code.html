the whole watcher is one set difference

one subtraction is the loop

seen = current()# baseline once, at startup, not reported as arrivals
loop every POLL_SECONDS:
now = current()# the node's mempool, this instant
arrivals = now - seen# set difference: txids present now, absent before
for txid in arrivals:
print(describe(txid))# report each new tx with its fee and size
seen = now# remember, so next tick shows only the next arrivals
The back-arrow is the state carried forward: seen = now feeds the next tick, so each pass reports only what is genuinely new.
