# `_template` — the copy-me course

This folder is a **complete, valid example** of the pieces a course is made of: a `course.yaml`, a `slots.lock.json`, lessons demonstrating most block types (prose, video, quiz, code in TypeScript and Rust, wallet-funding, program-explorer, deployed-program-card, and a reflection — `parsons` is the one it does not yet cover), and a translation overlay under `l10n/`.

## Use it

```bash
cp -r courses/_template courses/<your-slug>
rm -rf courses/<your-slug>/l10n        # ← don't skip this
```

**Delete `l10n/` immediately after copying.** It is a translation of *this template*, and `cp -r` brings it along — leave it in place and your new course ships claiming a Portuguese version whose title is "Curso Modelo". Add your own `l10n/<locale>/` later, if and when someone translates the course.

Then edit `course.yaml` (change `id`, `slug`, `sourceLocale`, `title`, `creator`, `modules`), rename the lesson folders, and replace the block content. Rename the lesson `id`s and the `course.id` — every id must be unique and correctly prefixed.

Don't hand-edit `slots.lock.json`; it's regenerated by the tooling.

## `l10n/pt-BR/` — the translation example

`l10n/pt-BR/` shows the shape of a translation overlay against this template's own (English) content. Its strings are illustrative placeholders, not a real translation. It demonstrates the parts that are easy to get wrong:

- `strings.yaml` keyed by module key, lesson slug, block key, question id, option id and test case id — never by array position. The exceptions are `hints` and `tutorNotes`, which the source stores as bare lists with no ids, so those are keyed by index.
- Translated prose as a real `.md` file at the mirrored path, keeping the source filename and its image links untouched.
- A localized image overriding its source counterpart by filename.
- **Partial coverage on purpose** — only 2 of the 5 lessons are covered, and the `rs` code block is omitted entirely. Everything left out simply renders in the source language, which is exactly how a real translation behaves while it's in progress.

The full rules are in [Translations](../README.md#translations). Note that the app does not render overlays yet — see the status note there.

## It is never published

The template is **not** a real course and never appears on the platform — it's only here as an example to copy. It *is* checked by CI, on purpose: that keeps it a guaranteed-valid reference that can't quietly go stale.

See [`../README.md`](../README.md) for the full course format and rules.
